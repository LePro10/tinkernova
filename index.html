Privacy

Tinkernova sends anonymous gameplay events (discoveries, choices, merges, device type, load time) so the pacing can be balanced. Each browser tab gets a random session id that is never stored. No cookies, no account, no personal data. Your save stays on your device (or in your portal account). Feedback text is only stored if you send it.
